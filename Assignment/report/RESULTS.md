Discuss growth within each algorithm/condition and compare algorithms within each row. Short runs are sensitive to scheduler activity, caches, Python/runtime overhead and noise. The benchmarks contain repeated transport-time keys because many requests revisit the same 69 reachable farms. Median-of-three helps on ordered data but is not a worst-case guarantee. Do not conclude that reversed data necessarily causes quadratic behavior for this implementation.
